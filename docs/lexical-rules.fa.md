# قواعد واژگانی پیاده‌سازی‌شده تا این مرحله

این سند وضعیت فعلی Lexer را از قواعد نهایی زبان جدا می‌کند. فاصله‌ها، توضیح‌ها، شناسه‌ها، کلیدواژه‌ها، عدد صحیح، رشته، کاراکتر، عملگرها، جداکننده‌ها و خطاهای پایه پیاده‌سازی شده‌اند.

## قواعد فعلی

| دسته | قاعده |
|---|---|
| حرف | یکی از `A-Z` یا `a-z` |
| شروع شناسه | حرف یا `_` |
| ادامهٔ شناسه | حرف، رقم `0-9` یا `_` |
| شناسهٔ بیش از ۲۵۶ بایت | توکن `INVALID` |
| عدد صحیح | یک یا چند رقم ده‌دهی، بدون علامت؛ منفی به‌عنوان عملگر جداگانه اضافه خواهد شد |
| رشته | متن داخل `"..."`؛ escape به‌صورت backslash به‌همراه نویسهٔ بعدی خوانده می‌شود؛ حداکثر ۲۵۶ نویسهٔ مقدار |
| کاراکتر | دقیقاً یک نویسهٔ مقدار داخل `'...'`؛ escape یک نویسهٔ مقدار حساب می‌شود |
| عملگرها | `++`, `--`, `-`, `!`, `^`, `*`, `/`, `%`, `+`, `<`, `<=`, `>`, `>=`, `==`, `!=`, `&&`, `||`, `=` |
| جداکننده‌ها | `(`, `)`, `[`, `]`, `{`, `}`, `,`, `;`, `:` |
| کلیدواژه | `array`, `boolean`, `char`, `else`, `false`, `for`, `function`, `if`, `integer`, `print`, `return`, `string`, `true`, `void`, `while` |
| فاصله | space، tab، LF یا CR؛ از جریان توکن حذف می‌شود |
| توضیح خطی | از `//` تا پایان خط؛ حذف می‌شود |
| توضیح بلوکی | از `/*` تا نخستین `*/`؛ حذف می‌شود |

Lexer ابتدا کل واژه را به‌عنوان شناسه می‌خواند و سپس آن را با مجموعهٔ کلیدواژه‌ها مقایسه می‌کند؛ بنابراین یک واژهٔ کلیدواژه‌ای به‌اشتباه شناسه نخواهد شد. عملگرهای چندنویسه‌ای مثل `++`, `<=`, `==` و `&&` پیش از عملگرهای تک‌نویسه‌ای تشخیص داده می‌شوند تا قاعدهٔ maximal munch رعایت شود.

مرجع B-Minor شکل استاندارد `<=` را دارد؛ راهنمای فاز اول برای مثال maximal munch، `=<` را به‌کار برده است. برای پوشش صریح مثال پروژه، Lexer فعلاً `=<` را نیز به‌عنوان یک عملگر واحد می‌پذیرد؛ lexeme اصلی بدون تغییر نگه داشته می‌شود. نویسه‌های ناشناخته مثل `&` تنها به‌صورت `INVALID` گزارش می‌شوند. توضیح بلوکی، رشته یا کاراکتر بسته‌نشده نیز `INVALID` است. طول شناسه بیش از ۲۵۶ بایت و رشته با بیش از ۲۵۶ نویسهٔ مقدار نامعتبر است. هر توکن نوع، lexeme و نام فایل/خط/ستون دارد؛ در پایان نیز توکن `EOF` ساخته می‌شود.

## محدودیت‌های فعلی

- شناسه‌ها بر مبنای ASCII/بایت پردازش می‌شوند؛ شناسه‌های غیر ASCII در محدودهٔ پیاده‌سازی فعلی نیستند.
- آزمون‌های maximal munch، دسته‌بندی عملگرها و جداکننده‌ها و خطاهای پایه در `tests/lexer_tests.cpp` نگهداری می‌شوند.
- `=<` تنها به‌دلیل مثال راهنمای فاز اول پذیرفته شده و در مرجع B-Minor عملگر استاندارد `<=` است.
