# B-Minor Compiler Front-End

پروژهٔ آموزشی سه‌فازه برای زبان **B-Minor**، با پیاده‌سازی C++ و یک مخزن Git پیوسته.

## وضعیت فعلی

- فاز ۱: اسکلت پروژه و بخش پایهٔ Lexer برای شناسه‌ها، کلیدواژه‌ها، فاصله‌ها و توضیح‌ها پیاده‌سازی شده است.
- هنوز literalها، عملگرها، Parser، AST و highlighter ساخته نشده‌اند.
- فازهای ۲ و ۳: فعلاً فقط در برنامهٔ توسعه ثبت شده‌اند.
- استاندارد ساخت فعلی: C++17 و CMake.

## ساخت و اجرا

```sh
cmake -S . -B build
cmake --build build
./build/bminor --help
```

## ساختار پوشه‌ها

- `include/bminor/` — سرآیندهای عمومی پروژه
- `src/` — پیاده‌سازی برنامه
- `tests/` — آزمون‌ها
- `docs/` — مشخصات و تصمیم‌های طراحی
